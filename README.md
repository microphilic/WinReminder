# WinReminder
Windows için basit bir not alma uygulaması
## Hakkında
WinReminder, Windows için basit bir not alma uygulaması olup modern C++ dil özellikleri ve yerel Windows API'leri kullanarak sade, hafif ve güvenli bir uygulama olmayı amaçlar.
## Kullanılan teknolojiler
- Visual C++ 2026 (v14.51)
- Windows 11 SDK (v10.0.28000)
- Microsoft Foundation Classes
## Derleme
Depoyu klonladıktan sonra Visual Studio 2026 kullanarak kaynak kodundan derleme yapabilirsiniz. **"C++ masaüstü geliştirme"** iş yükü yüklü olmalıdır.
## Kurulum
x64 mimarisi için MSI paketi sunulmuştur.
